##  免責事項

- 本ツールはGemini APIの無料枠での利用を想定しています。短時間に大量のリクエストを送信すると、APIのクォータ制限により一時的に利用できなくなる場合があります。
- 翻訳結果の正確性はAIモデルに依存します。重要な内容については必ず原文と照らし合わせて確認してください

Gemini APIを利用して、英語の学術論文PDFを専門用語の文脈を維持したまま日本語に和訳し、Wordファイル（.docx）として出力するアプリケーションです。並列処理により、長大な論文も高速に翻訳可能です。

##  主な機能

- **専門領域特化翻訳**: 情報通信工学、人間工学、行動心理学の文脈に最適化されたプロンプトを採用。
- **並列処理実装**: `ThreadPoolExecutor` により複数のチャンクを同時並行で翻訳し、処理時間を大幅に短縮。
- **高精度なテキスト抽出**: `PyMuPDF` を使用し、論文特有の2段組レイアウトを考慮したテキスト抽出。
- **カスタム出力**: ユーザーが指定したタイトルとファイル名でWordファイルを生成。
- **堅牢なエラーハンドリング**: APIのレート制限（429）やサーバーエラー（503）に対する指数バックオフ再試行機能を搭載。

## 🛠 セットアップ

### 1. リポジトリのクローン
```bash
git clone [https://github.com/](https://github.com/)[YOUR_USERNAME]/[YOUR_REPOSITORY_NAME].git
cd [YOUR_REPOSITORY_NAME]
```

### 2. 依存ライブラリのインストール 
```bash
pip install streamlit pymupdf google-genai python-docx python-dotenv
```

### 3. 環境変数の設定
プロジェクトのルートディレクトリに`.env`ファイルを作成し、以下の内容を記述してください
```
GEMINI_API_KEY=your_gemini_api_key_here
```

## 使い方
1. アプリケーションを起動します：
```bash
streamlit run [FILENAME].py
```
2. ブラウザで開いたUIから、翻訳したいPDFファイルをアップロードします
3. Wordファイル内の見出しと出力ファイル名を入力します
4. 使用するGeminiモデルを選択し、「翻訳を開始」をクリックします
5. 翻訳完了後、「翻訳後のWordファイルをダウンロード」ボタンから結果を取得します
